# Dynamic exposed: a long-prompt-heavy mixture. Mooncake's tool/agent traffic with a quarter of
# requests at its p99 prompt length, so the mixture's mean context is 22 k tokens and the KV token
# budget, not the sequence cap, is what limits the batch: 62 sequences instead of 256. 10 rps, which is
# 0.30x the analytic rated capacity of 33 and about the measured SLO capacity at a 0.95 cap: at freeze
# time p2c attained 0.9825 and least_queue_tokens 0.8395, the widest spread between the two on any load
# in the suite.
#
# Why it is in the suite: this is where a policy that counts requests is measuring the wrong quantity.
# One admitted 61 k-token request costs a replica what twenty-five ordinary ones cost, so
# least_requests and least_queue_tokens can only be told apart on a load like this one. It is also the
# regime where chunked prefill decides how much of one request's prefill everybody else pays for.
name = h4-long-prompt-mixture
seed = 20260906
duration_s = 120
warmup_s = 15

# -- fleet: a 70B-class model on 8xH100 per replica, identical in every held-out file ---------------

# throughput; 6.2's convention puts all overhead in the fixed term. step_base_ms is the 7.46 ms weight
# read at 70% bandwidth utilization plus 2.75 ms fixed overhead, step_per_kv_ktoken_ms is the
# bandwidth term, and kv_capacity_tokens is the primer's 1.37 M per replica (calibration.md 5.3 uses
# the same figure). Replica count is not a calibrated number: calibration.md 9.2 records that no public
# source gives a fleet size.
replicas = 32

# -- load: calibration.md scenario B "agent-2026" (Mooncake toolagent + TraceLab) -----------------
# prompt_mean/prompt_cv: Mooncake toolagent input mean 8,596, CV 1.28 [measured-here, 3.1 and 10].
# output_mean/output_cv: Mooncake toolagent output mean 182, CV 1.33 [measured-here, 3.1, 3.4]. Note
# calibration.md 3.1's warning that the median is 30 against a mean of 182 — very skewed, and the
# lognormal sampler reproduces that shape.
# The long mode is the same trace's input p99, 61,671 tokens [measured-here, 3.1], with output at its
# p99 of 898. 25% is a deliberate stress weight, not a measured one: calibration.md 4.2's nearest
# proxy, the continuation fraction, has measured endpoints of 3.3% and 76.1% with a [GUESS] fleet
# default of 25%, so this sits at that default.
# The mixture is 60.6:1 input:output — inside the 0.32:1 to 264:1 span calibration.md 3.2 measures, and
# firmly in the prefill-bound half of it. Analytic rated capacity is 33 rps; 10 rps is 0.30x, and the
# gap is the same saturation-versus-SLO gap documented in h2.
